# Plan - Find a Spoon

## Goal

Ship a free offline room hunt a child and a grandparent can do together. One huge line names the thing. The phone keeps the place in the hunt.

## Approach

1. App Store Connect has no rejected version waiting.
2. Build Find a Spoon in Expo: three rooms, Found it, Not here, and a saved place.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Picture lists, outing plans, dice, dinner answers, household places, tapped sentences, and copy-the-line are already in this pipeline. Camera scavenger hunts already fill the store. This one is a single huge line and two taps, with no camera and no network.
